## 🚀 Getting Started

### Prerequisites

- [JDK 17+](https://adoptium.net/) installed
- Maven or Gradle (or use the included wrapper, if present)
- Check your Java version:

  ```bash
  java -version
  ```

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/rowshanara01/your-repo-name.git
   ```

2. Go into the project folder

   ```bash
   cd your-repo-name
   ```

### Build and run with Maven

```bash
mvn clean install
mvn exec:java -Dexec.mainClass="com.example.project.Main"
```

### Build and run with Gradle

```bash
./gradlew build
./gradlew run
```

On Windows, use `gradlew.bat` instead of `./gradlew`.

### Run tests

```bash
mvn test        # Maven
./gradlew test  # Gradle
```
